# 职业外观

[返回开发文档](../README.md)

本目录集中维护同职业线外观选择功能，包含客户端渲染、服务端校验与保存、协议同步、操作入口和验收边界。后续目标扩展到十二条主职业线，诗人和舞娘分别覆盖。

当前已实现骑士／十字军两个分支；其余分支属于后续开发计划，资源候选或职业转职通过不代表职业外观已经实现或验收。
