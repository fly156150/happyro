## 共用环境

| 预设 | 视口 | deviceScaleFactor | 输入模式 |
| --- | --- | --- | --- |
| 电脑游戏 | 1280 × 800 | 1 | 默认桌面 |
| 平板游戏 | 1024 × 768 | 1 | `hasTouch: true, isMobile: true` |
| 手机游戏 | 430 × 860 | 2 | `hasTouch: true, isMobile: true` |
| 管理后台 | 1280 × 850 | 1 | 默认桌面 |

- 本机游戏从 `http://127.0.0.1:3338/applications/pwa/index.html` 启动，点击「进入游戏」打开游戏页，再点击「立即开始」。不要固定带构建号的旧 `api.html` 地址。
- 本机后台入口为 `http://127.0.0.1:8000`。
- 游戏需要先确认 Gateway 提供目标版本产物；需要重建时必须遵守完整 PWA `--all` 规则。
- 使用 Playwright Chromium 浏览器上下文分别设置视口。手机输出原图为 860 × 1720，其他端输出与视口尺寸相同。
- 客户端按粗指针检测选择触屏 UI，仅缩小桌面窗口不能替代触屏模拟。
- 同一账号顺序截图，切换前关闭上一端会话，避免挤掉登录。密码和令牌不保存到文档或版本配置。
- 等待地图、贴图、图标、文字及详情稳定后截图，不能仅以页面导航完成判断加载成功。收起无关提示、软键盘和聊天，检查私人信息。

## 跨端技能界面

输出：`happyro-responsive-skills.jpg`。

1. 沿用首图的平板和手机会话、角色与地图。
2. 点击「菜单」→「技能」，保留「全部转职」「全部技能」筛选。
3. 选择「金钱攻击」，等待技能图标与说明加载完毕。
4. 平板完整截图保存为 `tablet-skills.png`（1024 × 768）。
5. 手机完整截图保存为 `phone-skills.png`（860 × 1720）。
6. 按合成模板输出左右对比图，体现平板分栏与手机上下布局；不在截图中执行学习或重置。

## 截图调用与未记录参数

在已打开目标页面的 Playwright 会话中，可使用以下调用；`page` 和输出目录由调用方准备：

```javascript
await page.screenshot({ path: 'desktop.png' });
await page.screenshot({
  path: 'happyro-codex.png',
  clip: { x: 200, y: 60, width: 880, height: 680 }
});
```

上述只是截图 API 示例，不是自动登录和取景工具。首版未保存浏览器精确版本、完整相机姿态或场景动画时刻，因此不承诺重新取景逐像素一致；合成模板和输出尺寸可以复用。后续工具应记录浏览器版本、构建标识、实际位置、镜头、视口和输入文件哈希。
