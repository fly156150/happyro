# HappyRO 变更日志

本目录按日期记录 HappyRO 自有的用户可见功能、汉化、修复、构建和维护流程变更，不逐条复制上游提交历史。记录范围从 2026-08-24 建立的 `zh-cn` 维护基线开始。

本目录统一汇总以下 Git 仓库：

- `root`：工作区工具、部署和文档。
- `client`：`repos/happyro-client` Web 客户端。
- `server`：`repos/happyro-server` rAthena 服务端。

`repos/happyro-admin` 在自身的 `changelog/` 目录维护管理后台变更，不重复记录到本目录。`repos/happyro-gateway` 使用仓库内 `CHANGELOG.md`。

## 维护规则

- 路径固定使用 `<年>/<月>/YYYY-MM-DD.md`，同一天的修改追加到同一个文件。
- 最新日期排列在索引最前面。
- 日期日志每条记录以行内代码格式的 `[scope]` 开头；跨仓库变更使用 `[client/server]` 形式合并作用域。
- 只记录有维护价值的修改点；具体根因、实现细节和验收方法仍放在 `docs/history/bugfix/` 或 `docs/localization/`。
- 尚未提交的修改标记为“未提交”，提交后移除标记。
